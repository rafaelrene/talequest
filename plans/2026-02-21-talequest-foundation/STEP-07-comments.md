# Step 07 - Comments (Anonymous Enabled)

## Objective
Allow lightweight engagement while keeping entry friction low.

## Scope
- Anonymous commenting is enabled.
- Guest display name is required.
- No anti-spam system in phase 1 (explicit decision).

## Why
- Supports conversation early without forcing account creation.

## Deliverables
- Comment submission and rendering on story detail pages.
- Validation for required guest name and valid content payload.

## Acceptance
- Anonymous user can post comment with guest name.
- Invalid payloads are rejected predictably.
